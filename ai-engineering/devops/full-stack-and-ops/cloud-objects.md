# Cloud Objects

Serverless compute still needs a shape: run a function, or run a container without managing servers. This page answers that choice for AWS by comparing Lambda with Fargate.

## AWS Lambda

The question is when Lambda is the right shape and when Fargate is. The [Comparison](https://www.bluematador.com/blog/serverless-in-aws-lambda-vs-fargate) against AWS Fargate is Blue Matador's overview of both serverless architectures, compared on development, billing, and monitoring.
