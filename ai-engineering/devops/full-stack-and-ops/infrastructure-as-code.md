# Infrastructure As code

Cloud resources should be code, not clicks, so they can be reviewed, repeated, and rebuilt. The page starts with Terraform and how it compares with Ansible, then gives the beginner course that walks through it with labs.

The same notes are in [DevOps Courses](docker.md).

## Terraform

The first step is seeing Terraform build real infrastructure. [youtube course](https://www.youtube.com/watch?v=SLB_c_ayRMo) is freeCodeCamp.org's Terraform Course on automating your AWS cloud infrastructure. Terraform is often confused with configuration tools, and [Terraform vs Ansible](https://www.youtube.com/watch?v=n1zW_QHg8nY) is K21Academy's explanation of the difference between the two.


## Terraform course

After the overview, the hands-on path is a full course with exercises. [Terraform for beginners](https://www.youtube.com/watch?v=YcJ9IeukJL8) is KodeKloud's Terraform Tutorial for Beginners + Labs, a complete step-by-step guide.
