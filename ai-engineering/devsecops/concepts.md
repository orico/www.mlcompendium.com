# Concepts

Before the tools, the security vocabulary has to be clear. This page points at one visual way to learn it: a simplified set of information-security concepts.

The source is marked (cool): [Simplified concepts of infosec](https://securityzines.com/) by Rohit and Anshu. Security Zines teach each security concept as an illustrated zine, on the argument that graphics stay in memory longer than plain reading.
