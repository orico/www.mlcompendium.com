# MLOps Course

Reading about MLOps is not the same as practicing it. The shelf here is two Weights & Biases courses, first for model development and then for CI/CD.

The same notes are in [Continuous Integration](../devops/full-stack-and-ops/continuous-integration.md).

## Weights & Biases

Both courses come from the same vendor, so they follow one workflow from design to deployment.

The same notes are in [Experiment platforms](experiment-management.md#experiment-platforms).

The first course is about the model itself: [Effective MLOps for data scientists](https://www.wandb.courses/courses/effective-mlops-model-development) is tailored for effective model development, streamlining the ML workflow from design to deployment with W&B. Once a model can be developed that way, the second course automates its delivery: [CI/CD using GitOps and W&B](https://www.wandb.courses/courses/ci-cd-for-machine-learning) is the free CI/CD course on best practices for continuous integration and deployment of ML workflows.
