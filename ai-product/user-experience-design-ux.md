# User Experience Design (UX)

A product is used through an interface. The page starts with the general UX references a designer keeps open, each with its screenshot, and ends with growth-design case studies that show those ideas inside real products.

The first reference is a set of rules. [**Laws of UX**](https://lawsofux.com/) **is a collection of best practices that designers can consider when building user interfaces.** The screenshot below is its front page.
