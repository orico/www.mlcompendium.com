# How the makeover was done

The Ops half of the book went through the same cleanup as the rest, and this page records how. The rules below run from what was kept, to how each page was shaped, to how links and images were checked, and end with the counts for every address.

The book pages were rewritten in place. The table of contents was not edited. No unused file was deleted. Every content page was already in the table of contents.

The content itself was protected before any wording changed. Sentences were rewritten into clearer English, but facts, quotes, formulas, links, and images were kept.

With the content fixed, each page was given a shape. Each page was written with sections, subsections, and subsubsections where a part sits inside the level above. A heading was added only to name a block already on the page. Existing sections were ordered so the basics come before anything that depends on them. Each section, subsection, and subsubsection opens with one plain-English sentence saying what that part is about.

The blocks inside a page were then written in the form GitBook renders best. A formula was written as GitBook math, and a passage already in quotation marks was written as a quote. A video that is its own block and still plays was embedded, and a link to another page in this book was written as a page link when the file was exact. Tabs, columns, steppers, cards, expandables, hints, task lists, file blocks, and diagrams were used when the notes already had that shape.

Figures got the same care as text. Every figure has a caption, taken from the words next to the image, or from the heading when those words do not name the picture. An existing caption was rewritten into clearer English. An image copied from the web has a credit line. The credit is a source the notes already name, or the address the file was copied from. Google-hosted images that still loaded were saved into the book's image folder, and pages now point at those saved files.

Dead addresses were handled without losing what the author wrote. A Deprecated links section was added only where a link or an image no longer works, and that section keeps the original wording and the dead address. A replacement was used only when it was the same page, paper, file, or image, or the same article matched by title, by sentences, or by both. Towards Data Science links were searched on Medium, and only the same article was used. A replacement article names its author when the article itself gives that name.

Every change was then verified before moving on. Every rewritten link and every local image was checked again. Each page was compared with its original before the next page was started, and anything lost or added outside the plan was corrected. An address that the edit broke was put back.

Unlike the main book, this half had almost no gaps to fill. This book had no wrong-credit note, no TODO, and no did-not-watch note. One systemML notebooks item was marked didnt read. That address does not open, so the note stays with the address under Deprecated links. A section that is the same subject as another page or heading gets one sentence linking there.

The result can be counted. There are 738 URL occurrences in the rewritten pages. One address used twice counts twice, and one occurrence can sit in more than one row.

- Changed: 80 addresses in the rewritten pages are not the address that was there.
- Broken: 22 addresses are dead and sit in Deprecated links, with no working replacement in the body.
- Fixed: 78 addresses were dead or pointed at the old Towards Data Science site, and the body now has a working address for the same thing.
- Web searched and found: 56 searches found the same article, and that address is in the body.
- Web searched and not found: 3 searches were run and no same article was found.
- Paywalled: 160 pages stay in the body and are behind a membership or login wall, such as Medium.
- Others: 531 addresses were already fine and were left as they were, or they do not fit the rows above.
