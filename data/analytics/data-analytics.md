# Data Analytics

Analytics is the path from raw tables to questions a team can answer without a model yet. This page is that path as a free data analytics course, walked in videos from spreadsheets and dashboards through SQL to Python and Pandas.

## Course

The course starts with what the job is before any tool. CareerFoundry's [What Is Data Analytics? - An Introduction (Full Guide)](https://www.youtube.com/watch?v=yZvFH7B6gKI) is that framing. The spine of the path is Alex The Analyst's playlist: the Intro is [FREE Data Analyst Bootcamp!!](https://www.youtube.com/watch?v=rGx1QNdYzvs&list=PLUaB-1hjhk8FE_XZ87vPPSfHqb6OcM0cF&index=1), and How to plan it is [How to Become a Data Analyst in 2023 (Completely FREE!)](https://www.youtube.com/watch?v=CUBfrdDwznQ&list=PLUaB-1hjhk8FE_XZ87vPPSfHqb6OcM0cF&index=2).

The first tools are spreadsheets and dashboards. Excel 21-27 in the playlist starts at [Pivot Tables in Excel | Excel Tutorials for Beginners](https://www.youtube.com/watch?v=lH7HfwUFnYA&list=PLUaB-1hjhk8FE_XZ87vPPSfHqb6OcM0cF&index=22). PowerBI 33-41 starts at [How to Install Power BI | Building First Visualization | Microsoft Power BI for Beginners](https://www.youtube.com/watch?v=g0m5sEHPU-s&list=PLUaB-1hjhk8FE_XZ87vPPSfHqb6OcM0cF&index=34). Tableau 23-31 comes from a Simplilearn playlist instead: [Tableau Training For Beginners | Tableau Tutorial | Tableau Tutorial For Beginners | Simplilearn](https://youtube.com/watch?v=UWT14hhjsL0&list=PLEiEAq2VkUUKgEFXH1tBbHwq38oWYDScU&index=24).

Dashboards sit on data that lives in a database, so SQL comes next. SQL 3-20 starts at [Installing MySQL and Creating Databases | MySQL for Beginners](https://www.youtube.com/watch?v=wgRwITQHszU&list=PLUaB-1hjhk8FE_XZ87vPPSfHqb6OcM0cF&index=4).

The same notes are in [SQL](../engineering/sql.md).

For SQL questions, the practice video is [Solving Easy SQL Interview Questions on Analyst Builder](https://www.youtube.com/watch?v=ZHaYOC0H5KE&list=PLUaB-1hjhk8FE_XZ87vPPSfHqb6OcM0cF&index=70).

The path ends in code. Python 42-56 starts at [Installing Jupyter Notebooks/Anaconda | Python for Beginners](https://www.youtube.com/watch?v=WUeBzT43JyY&list=PLUaB-1hjhk8FE_XZ87vPPSfHqb6OcM0cF&index=43), and Pandas 57-64 starts at [Reading in Files in Pandas | Python Pandas Tutorials](https://www.youtube.com/watch?v=dUpyC40cF6Q&list=PLUaB-1hjhk8FE_XZ87vPPSfHqb6OcM0cF&index=58). As a single Course that covers the Python side in one sitting, freeCodeCamp.org has [Data Analysis with Python Course - Numpy, Pandas, Data Visualization](https://www.youtube.com/watch?v=GPVsHOlRBBI). Simplilearn's [Data Analytics Full Course In 5 Hours | Data Analytics For Beginners | Data Analytics | Simplilearn](https://www.youtube.com/watch?v=oQmxQh92Nh8&list=PLEiEAq2VkUUKgEFXH1tBbHwq38oWYDScU&index=2) is the long-form alternative, with the author's own verdict: Not sure if needed.
