# Data Governance

Someone has to own who may change the data and what “good” means across teams.
This page collects definitions, build guides, and starting steps for data governance.

The same notes are in [Data Fabric](database-architecture-and-modeling.md#data-fabric) and [Data Lineage](data-lineage.md).

- Could you use some help with the implementation of your Data Governance within your organisation? [Definition](https://www.cleverrepublic.com/what-is/data-governance/) taken from DAMA
- Data governance is a set of practices and processes for managing important data across an organization. [What is](https://www.imperva.com/learn/data-security/data-governance/)
- Data governance controls are critical in ensuring that data is consistent and dependable, by Nick Goble. How to build [part 1](https://www.phdata.io/blog/snowflake-data-governance/)
- With Snowflake, you need to have a defined information architecture, process for providing access, and a group responsible for managing these rules and patterns, by Nick Goble. [part 2](https://www.phdata.io/blog/snowflake-data-governance-2/)
- BARC Reviews: Find the right Data, Analytics & CPM Software. [a very thorough article](https://bi-survey.com/data-governance/)
