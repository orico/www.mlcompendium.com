# Data Vision

A data team needs a vision that says what success looks like before the org chart is drawn. The page points at one worked example of that vision, written for a data team.

The vision comes before the team shape, and the team page picks up from here. The same notes are in [Data Teams](data-teams.md).

[Vision for a data team](https://medium.com/alan/vision-for-a-data-team-2eae845b8052) is Antoine Liz's write-up, opening with the line “Knowing where you want to go is the best way to arrive somewhere”, which is the whole argument for writing the vision first.
