# DOE Tools

This page is about Design of Experiments tooling rather than the theory itself.
It lists generators and notebooks such as Design-of-experiment-Python, doePy, PyDoe, and the factorial notebook linked below.

- Design-of-experiment (DOE) generator for science, engineering, and statistics - tirthajyoti/Design-of-experiment-Python. [Design of experiments](https://github.com/tirthajyoti/Design-of-experiment-Python)
- GitHub - tirthajyoti/doepy: Design of Experiment Generator. Read the docs at: https://doepy.readthedocs.io/en/latest/. [doePy](https://github.com/tirthajyoti/doepy)
- Factorial Designs — pyDOE 0.3.6 documentation. [PyDoe](https://pythonhosted.org/pyDOE/factorial.html)
- Factorial - Two-Level Three-Factor Design. [DOE Notebook](https://charlesreid1.github.io/empirical-model-building/factorial_2level_3factor.html#twolevelfactorial)
