# Deep Neural Time Series

Forecasting a series with a deep network does not have to mean building an LSTM from scratch. This page follows one library, NeuralProphet, from its documentation to a quick guide and then to tuning it.

The same notes are in [LTSM for time series](../predictive-ml/forecasting.md#ltsm-for-time-series).

The reference for NeuralProphet is [NP Docs](https://neuralprophet.com/code/forecaster.html), the NeuralProphet class documentation. With the API known, [Optimizing Time Series Forecasting with NeuralProphet: A Quick Guide](https://medium.com/@miritrope/optimizing-time-series-forecasting-with-neuralprophet-a-quick-guide-a08afe8216ac) is Miri Trope's quick guide to using it well. The last step is the settings: [Hyper Param Tuning](https://medium.com/eni-digitalks/unlock-the-neuralprophet-potential-hyperparameter-tuning-1905ccb87537) is Lavinia Guadagnolo on finding the optimal hyperparameters for a NeuralProphet forecast, which means knowing what each parameter does, where to set its values, and how they interact.
