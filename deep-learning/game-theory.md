# Game Theory

Some AI systems are not a single model minimizing a loss but players whose best move depends on what the others do.
This page is about game theory as it shows up in computer science and AI, and it starts from one illustrated overview.

[In computer science](https://www.analyticsvidhya.com/blog/2019/11/game-theory-ai/) is Sharoon Saxena's "Game (Theory) for AI? An Illustrated Guide for Everyone" on Analytics Vidhya. It calls game theory the oldest algorithm in artificial intelligence and walks through its types, the Nash equilibrium, and how it is used for AI.
