# Chat UI/UX

A model behind an API still needs a screen a person can type into, and most teams start from an existing chat interface rather than building one. This page goes from one ready chat assistant, to a curated list of web UIs, to two open interfaces you can run over your own models.

The first stop is a zero-config assistant. [next chat](https://github.com/ChatGPTNextWeb/ChatGPT-Next-Web?tab=readme-ov-file) is ChatGPTNextWeb's NextChat, a zero-config AI chat assistant with no API key needed, where you sign up and chat with GPT-5, Claude 4, Gemini 2.5, DeepSeek, and 100+ top models, pay as you go, on Web, iOS, macOS, and Android.

 <figure><img src="../.gitbook/assets/image (45).png" alt=""><figcaption><p>next chat</p></figcaption></figure>

The screenshot above is NextChat. For more options, [LLM WebUIs](https://github.com/JShollaj/awesome-llm-web-ui) is a curated list of awesome Large Language Model (LLM) web user interfaces. From that space, [Open Web UI](https://github.com/open-webui/open-webui) is a user-friendly AI interface that supports Ollama, the OpenAI API, and more.

 <figure><img src="../.gitbook/assets/image (46).png" alt=""><figcaption><p>Open Web UI</p></figcaption></figure>

The screenshot above is Open Web UI. For multimodal systems as well as text, [Lol LLMS UI](https://github.com/ParisNeo/lollms-webui) is ParisNeo's lollms-webui, the Lord of Large Language and Multi modal Systems Web User Interface.
