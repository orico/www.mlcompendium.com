# Vision

This page points at DINOv2, a self-supervised vision transformer.

The same notes are in [Deep Neural Machine Vision](../deep-learning/deep-neural-machine-vision.md).

1. [DINOv2](https://dinov2.metademolab.com/): A Self-supervised Vision Transformer Model. A family of foundation models producing universal features suitable for image-level visual tasks (image classification, instance retrieval, video understanding) as well as pixel-level visual tasks (depth estimation, semantic segmentation).

[Breast Augmentation Using Gen-AI](https://cohenori.medium.com/breast-augmentation-using-gen-ai-15492ab71f8b) (October 2024) is a vision-generation case, and the product frame is in AI Product.
