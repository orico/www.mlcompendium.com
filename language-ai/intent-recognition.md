# Intent Recognition

A chatbot has to know what the user wants before it can answer, and that is intent classification. The page has one source, an archived note on what intent classification is and how you can use it.

The same notes are in [Chat Bots](../generative-ai/chat-bots.md) and [Document classification](foundation-nlp.md#document-classification).

The archived MonkeyLearn post, [What is intent classification, and how can I use it?](https://web.archive.org/web/20210122060415/https://monkeylearn.com/blog/intent-classification/), answers both questions in its title; the live address is kept at the end of the page.
