# Multi Language

This page lists multilingual embedding and cross-lingual model pointers.
The links include LASER-style multilingual sentence embeddings and cross-lingual language-model pretraining.

The same notes are in [LANGUAGE EMBEDDINGS](language-embeddings.md#language-embeddings) and [LANGUAGE TRANSLATION](language-detection-identification-generation-nld-nli-nlg.md#language-translation).

- Our natural language processing toolkit, LASER, performs zero-shot cross-lingual transfer with more than 90 languages and is now open source. [Fb’s laser](https://engineering.fb.com/ai-research/laser-multilingual-sentence-embeddings/)
- PyTorch original implementation of Cross-lingual Language Model Pretraining. [Xlm](https://github.com/facebookresearch/XLM)
- Facebook AI is open-sourcing XLM-R, a multilingual model that uses self-supervised training to achieve state-of-the-art performance on four cross-lingual understanding benchmarks. [xlm-r](https://ai.facebook.com/blog/-xlm-r-state-of-the-art-cross-lingual-understanding-through-self-supervision/)
