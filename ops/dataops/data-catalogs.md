# Data Catalogs

This page is a short note on data-catalog tools, and what a data catalog is.

## Tools

This section is the catalog product named here, and a definition of a data catalog.

[Alation](https://www.alation.com/)

> A [data catalog](https://www.alation.com/product/data-catalog/) is a collection of metadata, combined with data management and search tools, that helps analysts and other data users to find the data that they need, serves as an inventory of available data, and provides information to evaluate fitness of data for intended uses.
