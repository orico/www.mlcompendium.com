# How the makeover was done

- The book pages were rewritten in place. The table of contents was not edited.
- No unused file was deleted. Every content page was already in the table of contents.
- Sentences were rewritten into clearer English.
- Facts, quotes, formulas, links, and images were kept.
- Each page was written with sections, subsections, and subsubsections where a part sits inside the level above.
- A heading was added only to name a block already on the page.
- Existing sections were ordered so the basics come before anything that depends on them.
- Each section, subsection, and subsubsection opens with one plain-English sentence saying what that part is about.
- A formula was written as GitBook math, and a passage already in quotation marks was written as a quote.
- A video that is its own block and still plays was embedded, and a link to another page in this book was written as a page link when the file was exact.
- Every figure has a caption, taken from the words next to the image, or from the heading when those words do not name the picture. An existing caption was rewritten into clearer English.
- An image copied from the web has a credit line. The credit is a source the notes already name, or the address the file was copied from.
- Tabs, columns, steppers, cards, expandables, hints, task lists, file blocks, and diagrams were used when the notes already had that shape.
- A Deprecated links section was added only where a link or an image no longer works.
- That section keeps the original wording and the dead address.
- A replacement was used only when it was the same page, paper, file, or image, or the same article matched by title, by sentences, or by both.
- Google-hosted images that still loaded were saved into the book's image folder.
- Pages now point at those saved files.
- Every rewritten link and every local image was checked again.
- Each page was compared with its original before the next page was started, and anything lost or added outside the plan was corrected.
- An address that the edit broke was put back.
- Towards Data Science links were searched on Medium, and only the same article was used.
- This book had no wrong-credit note, no TODO, and no did-not-watch note. One systemML notebooks item was marked didnt read. That address does not open, so the note stays with the address under Deprecated links.
- A replacement article names its author when the article itself gives that name.

There are 738 URL occurrences in the rewritten pages. One address used twice counts twice, and one occurrence can sit in more than one row.

- Changed: 80 addresses in the rewritten pages are not the address that was there.
- Broken: 22 addresses are dead and sit in Deprecated links, with no working replacement in the body.
- Fixed: 78 addresses were dead or pointed at the old Towards Data Science site, and the body now has a working address for the same thing.
- Web searched and found: 56 searches found the same article, and that address is in the body.
- Web searched and not found: 3 searches were run and no same article was found.
- Paywalled: 160 pages stay in the body and are behind a membership or login wall, such as Medium.
- Others: 531 addresses were already fine and were left as they were, or they do not fit the rows above.
